② 生成的 emos-sign.plugin
在上方填写用户名后自动生成
③ 具体步骤
1
建一个公开仓库

打开 github.com/new → 仓库名填 emos-sign → 选 Public → Create repository。
必须是 Public，Private 仓库 Loon 拉不到（会 404）。

2
上传 emos-sign.js

仓库页 → Add file → Upload files → 把 emos-sign.js 拖进去 → Commit changes。
文件名保持 emos-sign.js。

3
上传插件文件

点上面的「下载 emos-sign.plugin」，然后同样 Add file → Upload files 传上去。
没有下载成功的话，用「复制全文」→ Add file → Create new file → 文件名写 emos-sign.plugin → 粘贴 → Commit。

4
在 Loon 里订阅

Loon → 配置 → 插件 → 右上角 + → 从 URL 添加 → 粘「插件订阅地址」→ 保存。
然后进插件填 Token，方法同之前。

④ 排错
导入提示 404 / 找不到文件 仓库是不是 Private；用户名、仓库名、分支、文件名有没有打错；刚建仓库时分支可能叫 master 而不是 main，去仓库首页确认一下。 插件导进来了，但定时不跑 / 日志报脚本加载失败 说明 script-path 那个地址不对。打开「脚本地址」，浏览器直接访问应该能看到 JS 源码而不是 404。 raw 地址打不开 换 cdn.jsdelivr.net 线路重新生成，把两个文件都传好后等几分钟再试。 改了脚本想生效 Loon 对远程脚本有缓存：插件列表里删掉重新添加，或换个文件名（比如 emos-sign-v2.js）并在插件里同步改地址。
本地生成，不会上传任何内容到服务器 · 你的用户名只用于拼接地址
